# Mesa de páginas: tudo o que ela faz

Editor visual para criar sites e landing pages arrastando e soltando. Cada projeto tem várias páginas; todas compartilham o mesmo Design System.

## 1. Barra de cima
- **← Voltar** (ou Esc sem nada selecionado).
- **Seletor de página** e **Páginas**: criar, duplicar, renomear, excluir, definir início, página privada, campanha.
- **Links**: mapa de links entre páginas, atualização dos menus e verificador de links quebrados.
- **Fontes**: lista as fontes usadas; instalar do Google Fonts, enviar a fonte do tema ou trocar.
- **Computador 1440 · Tablet 768 · Celular 390 · 3 telas** (os três lado a lado). O que você muda no tablet ou celular vale só ali.
- **Zoom − / +**, porcentagem e **Ajustar à tela**.
- **Desfazer / Refazer** (Ctrl+Z, Ctrl+Y).
- **Livre**: arraste qualquer elemento para onde quiser (Alt+arrastar duplica).
- **Desenhar**: pincéis sobre a página.
- **IA**: comandos no layout (por exemplo, "criar perguntas frequentes", "fundo escuro", "duas colunas", "melhorar a hierarquia", "alta conversão").
- **Prévia**: a página funcionando, em tela cheia.
- **Versões**: salvar, restaurar, comparar, aprovar (até 25).
- **Sistema**: o Design System do site (item 5).
- **Importar** e **Exportar** (item 7). Indicador de "Salvo".

## 2. Barra da esquerda (abre ao clicar, recolhe com Esc, 📌 fixa)
- **Elementos** (arrastar para a página ou clicar para inserir; ★ marca favoritos):
  - Básicos: Seção, Contêiner, 2 e 3 colunas, Bloco, Título, Texto, Imagem, Vídeo, Botão, Ícone, SVG, Lista, Divisor, Espaço, Link (área clicável), Selo, Logo do projeto, Formulário, Campo, Caixa de seleção, Opção.
  - Formas: retângulo, retângulo arredondado, círculo, triângulo, losango, hexágono, estrela, seta, balão, linha, anel.
  - Avançados: Menu, Acordeão (FAQ), Abas, Contagem regressiva, Tabela, Galeria, Carrossel, Antes e depois, Pergunta que revela a resposta, Linha do tempo, Passo.
- **Blocos**: seções prontas já preenchidas com o briefing do projeto (cabeçalho, hero, benefícios, problema e solução, como funciona, sobre, oferta, planos, depoimentos, perguntas, logos, formulário, chamada final, rodapé) e 16 blocos "Aula · …" (capa, galeria, carrossel, antes e depois, cartões, passos, perguntas, citação, vídeo, sequências horizontal/vertical/zoom, estação de mapa). O que falta fica entre [colchetes].
- **Camadas**: árvore da página com buscar, ocultar, bloquear, duplicar, excluir e arrastar para reordenar.
- **Biblioteca**: componentes globais (editar o principal atualiza todas as páginas), seus blocos e páginas salvos para todos os projetos, e temas importados (ZIP, Elementor, HTML, Envato).
- **Assets**: imagens do Studio, ícones e fontes.
- **Referências**: layouts que você admira, só para estudar a estrutura.
- Modelos de página: Captura de lead, Oferta, Serviço local, Evento e 3 de Aula (faixas, mapa, vertical), ou página em branco.

## 3. Barra da direita (aba lateral)
- **Conteúdo**: os campos do elemento (texto, imagem da biblioteca ou endereço, link, estilo do botão, nova aba, itens de lista, perguntas e respostas, abas, tabela, legendas do carrossel, antes e depois etc.).
- **Estilo**: tipografia, fundo, borda, sombra, cores do Design System.
- **Layout**: espaçamento, flex, grade, posição, tamanho.
- **Avançado**: animação ao aparecer, classes CSS, CSS personalizado.
- **Responsivo**: valores só do tablet ou do celular, com botão para restaurar o valor herdado.

## 4. Na página
- Clique seleciona; duplo clique edita o texto direto; botão direito abre o menu.
- Arrastar mostra a distância em pixels, alinha nas guias (snap) e solta **dentro de um contêiner**.
- Alças para redimensionar, tamanho mostrado ao lado.
- Réguas, guias arrastáveis, Copiar/Colar/Duplicar, Agrupar/Desagrupar, setas movem 1 px (Shift = 10 px).
- Navegação de aula por página: horizontal, vertical ou mapa com zoom.

## 5. Sistema (Design System)
Cores (com "puxar do Kit de marca do projeto" e cores extras), fontes, tipografia por nível, espaçamentos, bordas e sombras. Mudou ali, muda em todas as páginas.

## 6. Versões e aprovação
Salvar versão agora, restaurar, comparar, duplicar, excluir e marcar como **Aprovada**.

## 7. Importar e exportar
- **Importar**: Elementor (.json e Kit), HTML, JSON do Studio e temas (ZIP/Envato). Se falta uma fonte, o sistema avisa e oferece instalar do Google, enviar ou mostrar o nome.
- **Exportar**: HTML, ZIP do site (páginas ligadas), Elementor (.json), Kit do Elementor (.zip), CSS e JSON do Studio. Fora da Mesa: tema de WordPress e link para o cliente aprovar.

## 8. Atalhos (estilo Photoshop)
| Atalho | O que faz |
|---|---|
| **Espaço** (segurar) + arrastar | Move a prancheta (mão) |
| **Z** (segurar) + clique | Aproxima o zoom |
| **Z + Alt** + clique | Afasta o zoom |
| **Alt + roda do mouse** | Zoom no ponto do cursor |
| **Ctrl +** / **Ctrl −** | Zoom mais / menos |
| **Ctrl 0** | Ajustar à tela |
| **Ctrl 1** | 100% |
| Ctrl Z / Ctrl Y | Desfazer / Refazer |
| Ctrl C / X / V / D | Copiar, recortar, colar, duplicar |
| Ctrl G / Ctrl Shift G | Agrupar / desagrupar |
| Ctrl S | Salvar |
| Delete | Excluir |
| Enter | Editar o texto |
| Setas (Shift = 10 px) | Mover elemento livre |
| [ e ] | Mover para trás / para frente na ordem |
| Alt + arrastar (modo Livre) | Duplicar |
| Esc | Soltar a seleção, depois sair |

Os atalhos de Espaço e Z não agem enquanto você digita um texto.
