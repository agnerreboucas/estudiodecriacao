# Ampliação Studio para WordPress — leia primeiro

Este pacote instala o **Ampliação Studio** (estúdio de marketing: campanhas, anúncios, roteiros de vídeo, Stories, landing pages, logo e leads) dentro do seu WordPress, junto com um **tema leve** para você montar as telas no **Elementor grátis**.

## O que vem no pacote
| Pasta/arquivo | Para que serve |
|---|---|
| `1-TEMA/ampliacao-studio-tema.zip` | O tema. **É o único arquivo que você precisa enviar** para começar: ele traz o plugin do Studio dentro e um instalador guiado. |
| `2-PLUGINS/ampliacao-studio-plugin.zip` | O plugin do Studio, separado (só use se for instalar sem o tema ou em outro site). |
| `3-DOCUMENTACAO/` | Estes documentos (PDF, HTML e texto). |
| `LICENCA.md` | Termos de uso (modelo; veja o aviso no próprio arquivo). |

## Caminho mais curto (5 passos)
1. WordPress → **Aparência → Temas → Adicionar novo → Enviar tema** → escolha `ampliacao-studio-tema.zip` → **Instalar** → **Ativar**.
2. O WordPress abre o **instalador** (Aparência → *Instalação do Studio*). Clique em **Instalar e ativar o Studio**.
3. Clique em **Baixar e ativar o Elementor grátis**.
4. Clique em **Criar as páginas base**.
5. Clique em **Ir para o Ampliação Studio**. Pronto.

Detalhes, problemas e instalação manual: `01-INSTALACAO`.

## O que você precisa saber antes
- **Elementor grátis é suficiente.** Nada do pacote exige o Elementor Pro (ver `04-ELEMENTOR-GRATIS`).
- A **IA** (textos, imagens, voz) usa as **suas** chaves de API, colocadas dentro do Studio (Configurações → Integrações). Elas ficam só no servidor. O custo de uso é cobrado pelos fornecedores das chaves, não por este pacote.
- Os projetos ficam salvos no seu site (pasta protegida em `wp-content/uploads/ampliacao-studio-data`). **Faça backup dessa pasta** junto com o site.
- Este pacote foi testado com um WordPress simulado e com os componentes do Studio no navegador. **Ainda não foi testado em um WordPress real.** Instale primeiro num site de teste.
