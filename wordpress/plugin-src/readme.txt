=== Ampliação Studio ===
Requires PHP: 8.0
Stable tag: 1.6.0

Instalação: Plugins → Adicionar novo → Enviar plugin → escolha o .zip → Ativar.
Depois: menu "Ampliação Studio" → Abrir o Ampliação Studio.
Dados: wp-content/uploads/ampliacao-studio-data (protegida; faça backup junto com o site).
Chaves de IA: dentro do Studio, Configurações → Integrações.
